# Las 738 ramas con blob distinto, leídas por grupo

HEAD de la comparación: `15c4b6b04` y, para el dist, el HTML posterior del consentimiento. El script no ha modificado código de fichas. Salida de trabajo: `/tmp/audit738/grupos.jsonl` y `matriz.tsv`.

Se tomaron las 738 filas `pendiente_contenido` de `docs/inventario/matriz-ramas.csv` (696 de octubre de 2026 y 42 de noviembre). Para cada rama, `git diff --raw` desde el merge-base con HEAD. Cada cambio se agrupó por ruta + blob de la rama + blob de HEAD. Salen **39.370 grupos únicos**. Un mismo diff repetido en muchas ramas cuenta una vez.

`git merge-file` probó cada grupo de texto cuyo blob no coincide. No se ha aplicado ninguno.

| Decisión | Grupos | Qué significa |
|---|---:|---|
| binario distinto | 24.723 | Foto u otro binario que también está aquí y el hash no coincide. No se ha abierto la imagen. |
| binario ausente | 4.364 | Binario que la rama tiene y HEAD no. |
| conflicto | 3.231 | El texto de la rama y el de HEAD tocan el mismo sitio. No se integra. |
| ausente (texto) | 1.836 | Fichero de texto que aquí no está. Muchos son CSV de SEO, notas y `public/` de ramas viejas, no una página nueva ya revisada. |
| no legible | 1.542 | El merge no pudo leer el blob. |
| aplica limpio | 1.246 | El texto de la rama entraría sin marcadores de conflicto. No se ha copiado: un ejemplo (`origin/enriquecer-fichas-niki-t1` sobre `comparador-coches-nuevos.ts`) añadiría bloques Euro NCAP y una URL de Toyota que HEAD no tiene. Meter los 1.246 del tirón reintroduce datos sin revisar. |
| generado distinto | 1.174 | Salida de generador. El build la reescribe. |
| absorbido | 760 | El merge no añade nada que HEAD no tenga ya. |
| log, no web | 458 | Censos, `hidden_files` y borradores. |
| generado ausente | 36 | Generador que aquí no está. |

Cero grupos de texto tenían el mismo blob que HEAD: después de las reescrituras, el fichero de la rama ya no es idéntico al actual aunque a veces el contenido útil ya esté absorbido.

Esto no declara el trabajo del equipo integrado. Declara, grupo a grupo, por qué no entra en esta tanda.
